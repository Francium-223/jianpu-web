简谱旋律查歌

输入一段旋律的唱名数字（1–7），查出它是哪首歌。 不需要写时值或八度记号（#5、,6、'1 写了更准）。 空格不分段；用逗号/分号/竖线分成多段会更准。

例子： 63731232 55532235 3211612655 66165535 532322 7656 5111156711

按曲名找

想给某一首补收录页/标签、或核对元数据时用这里：按曲名（或别名）调出它的卡片。 卡片里的「收录页」是确切页面，缺的会点名"待补充"；旁边可以直接粘贴链接保存。 卡片标题和「本谱一页」都通向这首的独立页面（原图 + 全部元数据）。

投稿 / 纠错（不用登录）

三件事：推荐收录（库里没有的歌）、纠错（这一首转错了）、元数据（曲名/出处/标签不对）。 填完点一下就行 —— 投稿会直接落到服务端并入库，不需要 GitHub 账号，也不需要打开 GitHub。
选纠错/元数据时会自动带上你刚才查询命中的那一份曲谱（先在上面查一次），作者就知道你说的是哪一份。




检索：滑窗逐音比较（代价模型：自然↔自然 0、自然↔带记号 1、写了记号却没对上 2、音级不同 4） → 按曲名归组取组内最优 → 热度破并列。查询完全在本地浏览器里跑，不联网。
